NoWebP Privacy Policy

Product: NoWebP (Chrome extension) · Effective date: 2026-08-30 · Last updated: 2026-08-30

NoWebP is a Chrome extension whose single purpose is to make confirmed static WebP images usable as PNG when downloading, copying, or saving them. Processing occurs locally in Chrome.

Information handled

To provide this functionality, NoWebP handles the source image URL, relevant Chrome download metadata, source image bytes, the locally generated PNG, and the user's relevant download, trusted copy, or NoWebP context-menu action. When NoWebP retrieves a source image, Chrome may attach cookies or other credentials applicable to that image's originating website. NoWebP does not read those credential values. NoWebP does not read clipboard contents.

How the information is used

This information is used only to locate and retrieve the source image, confirm from its bytes whether it is a supported static WebP, convert it locally to PNG, and complete the requested download, copy, or save operation. Animated WebP, unsupported content, and uncertain inputs are left unchanged.

Network disclosure

NoWebP contacts the source image's existing originating website only as necessary to retrieve that image, and only over HTTPS. HTTP sources are left to Chrome unchanged; NoWebP does not re-fetch them or rewrite them to HTTPS. The HTTPS origin receives the normal image request and any origin-applicable credentials Chrome attaches. No image, URL, clipboard, credential, download, or browsing/activity information is sent to the NoWebP developer or to an additional analytics, advertising, conversion, data-broker, or cloud service.

Storage and retention

NoWebP does not maintain persistent storage of source URLs, image bytes, generated PNG data, clipboard contents or history, credentials, download metadata, browsing activity, user actions, timestamps, or diagnostic records. Temporary URL/image/PNG data exists only in Chrome memory for the requested operation and is discarded with the relevant page or extension execution context. Files the user downloads and Chrome's normal Downloads entries remain under the user's and browser's control.

Clipboard

NoWebP requests clipboardWrite only. It writes a locally generated PNG for an eligible trusted standalone-image keyboard copy or after the user chooses "Copy WebP as PNG." It does not request clipboardRead, inspect existing clipboard content, or keep clipboard history.

Advertising and sharing

NoWebP has no advertising or analytics. It does not sell user data, use it for profiling, advertising, creditworthiness, or lending, or share it with data brokers or other additional third parties. The developer and other humans cannot access or read the data handled locally by the extension.

Remote processing and code

NoWebP uses no cloud processing or native helper. All executable logic is packaged in the extension. Retrieved source images are data for local conversion and are not executed as code.

Contact / support

Questions about this policy or NoWebP's behavior can be raised via this project's GitHub Issues page.
