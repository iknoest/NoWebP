NoWebP Test Lab

Known WebP samples with the exact behavior you should see if NoWebP is installed and working. Load extension/ as an unpacked extension first — see the README.

All sample files on this page are synthetic test patterns generated for this project — not third-party photographs — so there are no external licensing questions. Each one is encoded with the official libwebp tools and its container bytes were verified against the exact codec/feature case it's meant to test.

Known limitation: Chrome's built-in right-click “Copy Image” command is outside NoWebP's supported interception path — Chrome does not expose an event NoWebP can use there. Use NoWebP's own “Copy WebP as PNG” menu entry for a right-click copy workflow instead.
