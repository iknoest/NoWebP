NoWebP Test Lab

Known samples with the exact behavior you should see when NoWebP is active. Load extension/ as an unpacked extension first — see the README.

How NoWebP works:
  • Automatic conversion: Ordinary downloads of static WebP images automatically save as PNG. Non-WebP images and animated WebP are left untouched automatically.
  • Standalone keyboard copy: When viewing a static WebP image by itself in a browser tab, pressing ⌘C / Ctrl+C copies PNG image data to your clipboard.
  • Explicit context menu: Right-clicking an image gives you NoWebP's menu actions:
    • Copy image as PNG: copies static WebP and JPEG as PNG, and passes through PNG.
    • Save image as PNG…: saves static WebP and JPEG as PNG, and saves PNG via a standard save dialog.
  • Animated WebP: Animation is not flattened to static PNG. Copy/Save as static PNG is not supported for animated WebP; an explanatory notice is shown at the top of the page, and your clipboard/downloads remain untouched.
  • Chrome limitation: Chrome's built-in right-click “Copy Image” command is outside NoWebP's control due to browser platform limitations. Use NoWebP's “Copy image as PNG” menu item instead.
