Quick ways to use NoWebP

Right-click menu

Use Copy image as PNG and Save image as PNG… to normalize WebP, PNG, and JPEG images to PNG with full alpha channel support.

Standalone image

Press ⌘C or Ctrl+C on a standalone static WebP tab to copy it directly as standard PNG clipboard data.

Automatic downloads

Confirmed static WebP downloads convert to standard .png files automatically without extra steps.

Browser limitation note: Chrome's built-in “Copy Image” is outside extension control. Use NoWebP → Copy image as PNG when you need PNG clipboard data.
